blurb: Deep reinforcement learning that decides where industrial IoT tasks should run.
problem: Edge servers in industrial IoT networks get overloaded when tasks are offloaded without coordination, wasting compute and adding delay.
approach: Formulated task offloading as a Markov Decision Process and trained cooperating deep RL agents inside a Python simulation (digital twin) of the edge network.
result: An adaptive offloading policy that balances computational load as network conditions change.
